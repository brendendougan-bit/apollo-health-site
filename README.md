# Apollo Health

Pre-launch waitlist site for Apollo Health, served by GitHub Pages at https://apollo-online-health.shop.

- `index.html`: the site
- `privacy.html`: privacy and consumer health data policy (draft for attorney review)
- `media/`: images, hero film and audio
- `CNAME`: the custom domain

Waitlist signups go to Formspree: set the form id in `ENDPOINT` near the bottom of `index.html`.
